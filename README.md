# Анонимизированное CV

React-шаблон резюме с данными в JSON и готовой статической HTML-сборкой.

## Где что менять

- `data/cv.json` — весь текст резюме, опыт, технологии и 39 подробных технических тем.
- `src/Cv.jsx` — React-компоненты документа.
- `src/styles.css` — экранная, мобильная и печатная версии.
- `src/client.js` — переключение вкладок, клавиатурная навигация и кнопка печати.
- `docs/index.html` — готовый самостоятельный HTML; этот файл включается в Git вместе с исходниками.

## Сборка

Нужен Node.js 22 или новее.

```sh
npm ci
npm run build
npm run check
```

При сборке React рендерит JSON через `renderToStaticMarkup`. CSS и небольшой скрипт вкладок встроены в HTML. В готовом файле нет React runtime, загрузки данных, внешних шрифтов, аналитики и запросов к сторонним сервисам. Файл можно открыть с диска и переслать отдельно.

Изменение JSON требует повторного `npm run build`: статическая страница не читает JSON во время просмотра.

## Локальный просмотр

Откройте `docs/index.html` в браузере либо выполните:

```sh
npm run preview
```

Preview доступен на `http://127.0.0.1:4173`. Сервер слушает только loopback и отдаёт только собранный HTML. Для другого порта задайте переменную `PORT`.

Восемь вкладок: резюме, Stripe, PostgreSQL / pgvector, AI / RAG, Redis, Java / Spring, React / Next.js, Cloud / CI. Обычное резюме объединяет профиль, ключевой проект и предыдущий опыт; технические вкладки сохраняют развёрнутые описания.

## Печать

Кнопка «Печать / PDF» печатает выбранную вкладку. Для основного CV выберите «Резюме». Применяются отдельные стили A4: навигация и служебные кнопки скрываются. Без JavaScript содержимое остаётся читаемым последовательно.

## Анонимизация

Из идентифицирующих данных оставлено только имя Мария. Удалены фамилия, контакты, фото, личные ссылки, местоположение, название учебного заведения и семейные обстоятельства. Работодатели и проекты обозначены по предметной области. Годы опыта и профессиональные технологии сохранены.

Исходный персональный PDF и рабочие заметки не включаются в репозиторий. В сборке нет скрытых контактных данных, персонального JSON-LD и ссылок на исходные документы. Проверка отклоняет личные поля, email, телефонные номера, внешние ссылки и локальные пути в JSON. Это проверка явных идентификаторов; уникальные сочетания профессионального опыта всё ещё могут позволять узнать человека.

Материал по ключевому проекту собран из ранее подготовленного технического описания; предыдущий опыт — из существующего CV. Не добавлены непроверенные показатели нагрузки, проценты улучшений и даты текущего проекта. RAG в обзорах использует выборку структурированных данных; pgvector semantic search описан как отдельный поток.

## Сборка в репозитории и GitHub Pages

Готовый `docs/index.html` хранится рядом с исходниками, поэтому отдельный Node.js-сервер для хостинга не нужен. После правок сохраняйте в Git и JSON / исходники, и обновлённую сборку.

Для публикации через GitHub Pages можно выбрать ветку с этой сборкой и папку `/docs` в настройках репозитория. Включение Pages публикует содержимое; в рамках подготовки шаблона настройки хостинга автоматически не меняются.
