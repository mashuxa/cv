01

Модель данных PostgreSQL

Проектирование реляционной модели мероприятий, дат проведения, заказов, платежей, билетов, переписок и социальных групп. Использование внешних ключей, CHECK-ограничений, уникальных и частичных индексов для целостности данных. Применение JSONB для структурированных AI-результатов, метаданных и контекста операций, GIN-индексов для коллекций. Выделение схем media и social.

02

Управление конкурентностью

Применение row-level locking, SELECT FOR UPDATE и PostgreSQL advisory locks для резервирования мест, платёжных переходов, распределения пользователей по группам и операций с переписками. Атомарные upsert через ON CONFLICT, согласованный порядок захвата блокировок и идемпотентная обработка повторных запросов.

03

Фоновая обработка на PostgreSQL

Использование advisory locks для сериализации тиков платёжного планировщика, lease-механизма для захвата AI-заданий и FOR UPDATE SKIP LOCKED для пакетной очистки архивных данных без ожидания занятых строк. Хранение состояний задач и результатов в БД для продолжения обработки после перезапуска.

04

Оптимизация SQL и ORM

Использование проекций идентификаторов и загрузки полных сущностей только для итоговой страницы результатов. Устранение N+1 через пакетную загрузку связанных данных, сохранение пагинации на стороне БД вместо пагинации коллекций в памяти. Применение Slice-пагинации без дополнительных COUNT-запросов и ранжирование результатов средствами SQL.

05

Геопоиск и карта

Реализация поиска по радиусу и границам видимой области: bounding-box prefilter, точная проверка расстояния и сортировка по близости. Серверная grid-кластеризация с учётом масштаба карты и пользовательских фильтров, передача компактных агрегатов вместо полных карточек всех мероприятий. Загрузка для кластеризации только необходимых полей.

06

Semantic search на pgvector

Построение векторных представлений мероприятий и поисковых запросов через Spring AI EmbeddingModel, хранение в PostgreSQL / pgvector. Ранжирование по смысловой близости с учётом бизнес-фильтров и корректным продолжением порядка результатов между страницами. Использование HNSW (индекс быстрого поиска похожих объектов), версионирование векторов при смене модели, фоновое обновление и backfill отсутствующих представлений.

07

Персонализированные рекомендации

Разработка многофакторного подбора мероприятий по интересам, желаемому формату участия, социальной атмосфере, дополнительным условиям и географии. Объединение нескольких векторных сигналов, обработка обратной связи, исключение уже показанных событий и резервный подбор при недоступности AI-провайдера.

08

Эволюция схемы и доступ к данным

Версионирование схемы, индексов, ограничений и прав доступа через Flyway, forward-миграции существующих данных при изменении доменной модели. PostgreSQL RLS и grants для закрытия внутренних таблиц от прямого клиентского доступа. Интеграционные тесты миграций для чистой установки и обновления существующей схемы.
